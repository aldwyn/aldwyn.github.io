2. Next-Gen Airflow 3.3 & Air-Gapped K8s (Woven by Toyota)

At Woven by Toyota, I architected and executed the transition from Apache Airflow 2.10 to Airflow 3.3, leveraging the native Git DAG Bundles feature to cleanly isolate multi-tenant DAG repositories across disparate GitHub codebases while sharing unified underlying compute infrastructure.

I engineered end-to-end Terraform configurations codifying Fivetran, dbt, Snowflake, and GitHub infrastructure into versioned code. To accelerate container builds and ensure strict reproducibility, I migrated package management from legacy pipenv to uv.
